# ForgeVault Icon Assets

Place Windows icon assets here when the final mark is ready.

Expected files:

```text
forgevault-icon.svg
forgevault-icon-256.png
forgevault-icon.ico
```

Packaging will use `forgevault-icon.ico` automatically when it exists.

Icon direction:

- dark graphite base,
- controlled orange forge/layer/vault mark,
- readable at small Windows shortcut sizes,
- no rainbow colors,
- no decorative SaaS blob nonsense.
